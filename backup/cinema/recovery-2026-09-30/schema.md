# Формат FAST101-retrieved.tsv

UTF-8, табуляция, одна строка на пару profile + question_number. Всего 404 строки, 101 на R/J/K/M. Строки разных анкет не равны уникальным фильмам.

| Поле | Значение |
|---|---|
| profile | R, J, K или M |
| question_number | Исходный номер в сохранённой форме, 1–101 |
| title / ru_title / year / form_type | Метаданные из существующей HTML-формы без правок |
| rating | 1–5 — числовая оценка; 0 — не смотрел; ? — смотрел, оценку не помню; пусто — без ответа |
| heat | 0–3 только при числовой оценке; пусто — не задан или не принят из-за противоречия; это не 0 |
| status | watched, partial, not_watched, watched_forgot, unanswered |
| evidence_ids | Фрагменты evidence.md/evidence.json через точку с запятой |
| reported_source_time | Время сообщения, которое назвал поиск; не время независимой проверки |
| recovery_state | retrieval_summary: сведения извлечены через поисковый пересказ, не из полного дословного экспорта |
| source_form | Относительный путь к исходной форме |
| notes | Пояснения к неоднозначным строкам |

Для K Heat=0 соответствует «без огонька». Для других анкет нулевой Heat нужно читать вместе с источником, не смешивая его с отсутствующим значением.

Никакой автоматической замены старых значений по этому TSV выполнять нельзя. Расхождения между слоями сохраняются как разные наблюдения, пока нет исходных сообщений, подтверждающих их хронологию и смысл.
