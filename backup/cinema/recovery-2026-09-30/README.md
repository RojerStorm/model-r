## Как сохранено происхождение

[evidence.md](evidence.md) — запросы, ответы поиска и решения по неоднозначным результатам; [evidence.json](evidence.json) — те же сведения для обработки. Источники каждой строки обозначены идентификаторами e01-1 и т. п. Порядок и названия взяты из уже сохранённых форм, не из предположений поиска.

Для K «без огонька» кодируется как Heat=0 согласно самой форме; ему не приписывается дополнительная эмоциональная трактовка. Нелогичный 🧊 при «не смотрел» в фрагменте R81–101 оставлен в исходном свидетельстве, а в нормализованном Heat — пусто с пояснением.

R остаётся основной моделью; J/K/M — семейным контекстом. Ранний UI/UX-пилот R/J не включён. Obsession и Absentia (2011) не объединялись. Рабочий XLSX остаётся рабочей базой, GitHub — резервом.
